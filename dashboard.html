See your Task Bar Hero stats

👋 Welcome back — reconnect your last save folder.

A free, read-only companion that shows your heroes, gold, loot, runes and progress. It reads your save file and never changes the game.

  1. Click the blue Connect folder button (top‑right). Chrome or Edge will ask which folder to open.
  2. Paste this path into the dialog and press Enter, then click Select Folder:
    %USERPROFILE%\AppData\LocalLow\TesseractStudio\TaskbarHero
  3. If the browser asks, click View files / Allow. Your stats appear and keep updating live as you play.

Just one file? Connect file loads only SaveFile_Live.es3 — quick, but no history charts (the folder option also reads the game's backups to chart your progress over time).

🔒 Private & safe. Everything is decrypted and read on your own computer — nothing is uploaded, and the game is never modified. Chrome / Edge keep it live; other browsers load once (re‑pick to refresh).

👥 No account, no sign‑in. This is just a web page — anyone can open it and connect their own save the same way. Your data never leaves your device, and no one else can see it. (The optional Crew leaderboard is the one exception — it shares a few brag‑stats only if you opt in, and never your save file.)

🧭 On Firefox or Safari? The one‑click folder option needs Chrome or Edge. You can still use Connect file below to load SaveFile_Live.es3 — or open this page in Chrome / Edge for live updates & history.

Trouble connecting? (e.g. “this folder contains system files”)

That message is your browser blocking the folder for safety — it’s not a bug in this tool. Any of these gets you in:

  1. Use Connect file instead and pick just SaveFile_Live.es3 — single files usually aren’t blocked.
  2. Drag & drop your SaveFile_Live.es3 anywhere onto this page. This always works (it bypasses the folder picker entirely).
  3. Use the desktop app — it reads the folder directly with no browser restrictions, auto-finds your save, and updates live.

Tip: when the folder dialog opens, paste the path above and select the TaskbarHero folder itself (not its parent), then click Select Folder.
